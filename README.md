# My Portfolio / Resume Application

A responsive and professional portfolio/resume web application built **entirely with Bootstrap**. This project showcases my skills, previous works, and experience in a simple, clean, and mobile-friendly design.

## 🚀 Features

- Fully **responsive layout** for desktops, tablets, and mobile devices
- Clean **single-page design** for easy navigation
- Sections for:
  - **About Me** – brief professional introduction
  - **Skills** – list of technical and soft skills
  - **Profolio / Works** – showcase of previous work with links/screenshots
  - **Service** – what can I do for you
- Built using **Bootstrap 5** for modern layout and components
